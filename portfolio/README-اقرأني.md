# دليل موقع محمد ياسر — كل تعديل ستحتاجه

> قاعدة ذهبية: بعد أي تعديل افتح `index.html` في المتصفح على جهازك وتأكد أنه سليم، ثم ارفع.
> وإذا اختفى شيء من الصفحة، فالسبب غالبًا فاصلة `,` أو قوس `}` ناقص في الملف الذي عدّلته.

---

## 1) شكل المجلد

```
index.html          ← النصوص العربية + الروابط + بيانات التواصل
css/style.css       ← الألوان والخطوط والتصميم
js/projects.js      ← مشاريعك (أهم ملف ستعدله)
js/i18n.js          ← الترجمة الإنجليزية لنصوص الموقع
js/script.js        ← الحركة والمنطق (لا تحتاج لمسه)
js/mockups.js       ← رسم نماذج الأجهزة (لا تحتاج لمسه)
images/             ← صورتك وصورة المشاركة والأيقونة
images/projects/    ← ضع هنا لقطات شاشة مشاريعك
```

---

## 2) إضافة مشروع جديد (الأهم)

كل بلوك `{ ... }` في `js/projects.js` = كارت واحد في "نماذج من أعمالي". الترتيب في الملف هو الترتيب في الموقع.

**الخطوات:**
1. ضع لقطة الشاشة في `images/projects/` (مثال: `menu2.png`). المقاس الأفضل: عرض 1400px للمواقع، و750px للموبايل.
2. افتح `js/projects.js` وانزل لآخر مشروع.
3. ضع فاصلة بعد `}` الأخيرة لتصبح `},`
4. الصق البلوك التالي بعدها (آخر بلوك بدون فاصلة بعده) ثم عدّل بياناته:

```js
  {
    id: 'menu-2',
    status: 'live',
    device: 'phone',
    mockup: 'menu',
    tone: 'teal',
    image: 'images/projects/menu2.png',
    link: 'https://رابط-المشروع.com',
    ar: {
      category: 'حلول المطاعم والكافيهات',
      title: 'اسم المشروع بالعربي',
      desc: 'وصف قصير في سطرين.',
      tags: ['QR Code', 'منيو تفاعلي']
    },
    en: {
      category: 'Restaurant & café solutions',
      title: 'Project name in English',
      desc: 'Short description.',
      tags: ['QR Code', 'Interactive menu']
    }
  }
```

**معنى الحقول:**

| الحقل | ماذا تكتب |
|---|---|
| `id` | اسم إنجليزي قصير غير مكرر. للتنظيم فقط ولا يظهر في الموقع |
| `status` | `'live'` = منشور، `'wip'` = قيد التطوير |
| `device` | `'phone'` موبايل، `'browser'` كمبيوتر، `'none'` صورة Mockup جاهزة منك بدون إطار |
| `mockup` | الشكل المرسوم لو لا توجد صورة: `'menu'` أو `'website'` أو `'dashboard'` |
| `tone` | لون الخلفية خلف الصورة: `'teal'` أو `'warm'` أو `'deep'` |
| `image` | مسار الصورة. اتركه `''` ليُرسم نموذج جاهز بدلها |
| `link` | رابط المشروع. اتركه `''` ليظهر "تفاصيل المشروع قريبًا" بدل الزر |
| `ar` / `en` | النصوص بالعربية والإنجليزية: `category` و`title` و`desc` و`tags` |

**ماذا سيظهر في كل حالة:**

| الحالة | النتيجة |
|---|---|
| رابط فقط | نموذج مرسوم متحرك + زر "زيارة المشروع" |
| صورة فقط | صورتك في إطار جهاز + "تفاصيل المشروع قريبًا" |
| صورة + رابط | صورتك في إطار جهاز + زر الزيارة |
| بدون الاثنين | نموذج مرسوم + "قريبًا" |

**الصور:**
- لقطة شاشة عادية: `device: 'browser'` أو `'phone'` ويوضع لها إطار تلقائيًا. اللقطة الطويلة تنزلق من الأعلى للأسفل عند الوقوف عليها بالماوس.
- صورة Mockup جاهزة صنعتها أنت: `device: 'none'` وإلا سيظهر إطار مزدوج.

**مشروع جديد من نفس النوع (منيو آخر مثلًا):** انسخ البلوك الأخير، غيّر `id` والصورة والرابط والنصوص.

**تعديل مشروع موجود:** لا تنسخ. عدّل نفس البلوك.

**حذف مشروع:** احذف البلوك كله من `{` إلى `}` مع الفاصلة التي بعده، وتأكد أن آخر بلوك لا تتبعه فاصلة.

**ترتيب المشاريع:** غيّر مكان البلوكات داخل الملف.

**حجم الكروت:** عند 4 مشاريع أو أقل تظهر كبيرة. عند إضافة الخامس تتحول كلها تلقائيًا لكروت أصغر (واحد يمين وواحد يسار) حتى لا تطول الصفحة. للتحكم يدويًا غيّر `window.PROJECTS_LAYOUT` في أول `projects.js` إلى `'auto'` أو `'large'` أو `'compact'`.

## 3) تغيير النصوص

- **العربي:** داخل `index.html` مباشرة. ابحث بـ Ctrl+F عن النص الذي تريده وعدّله.
- **الإنجليزي:** في `js/i18n.js`. لكل نص عربي في الصفحة مفتاح، مثل `data-i18n="hero.title"`. ابحث عن المفتاح نفسه في `i18n.js` وعدّل ترجمته.
- لو غيّرت نصًا عربيًا، غيّر ترجمته الإنجليزية أيضًا، وإلا سيبقى القديم في نسخة EN.

## 5) الصور

- **صورتك:** استبدل الملفات في `images/` بنفس الأسماء: `personal-photo-480.webp` و`-720.webp` و`-1000.webp` و`personal-photo.jpg` و`personal-photo-square.jpg`.
- **صورة المشاركة (تظهر عند مشاركة الرابط):** `images/og-image.jpg` بمقاس 1200×630.
- **الأيقونة:** `images/favicon.svg`.
- اضغط أي صورة جديدة قبل رفعها (يفضّل WebP أو JPG أقل من 200KB) حتى يبقى الموقع سريعًا.

## 6) الألوان والخط

كلها في أول `css/style.css`:

- **ألوان الوضع الداكن:** بلوك `:root`.
- **ألوان الوضع الفاتح:** بلوك `[data-theme='light']`.
- **البرتقالي الأساسي:** `--orange`، والتركواز: `--teal`.
- **خط العناوين:** `--f-display` (السطر 43 تقريبًا). الحالي Reem Kufi. بديل مقترح: Cairo.
- لو غيّرت الخط، غيّر أيضًا رابط Google Fonts في `<head>` داخل `index.html`.

## 7) رابط الموقع والمعاينة

لو غيّرت الدومين من `mohamed-yasser-pro.pages.dev` إلى دومين آخر، ابحث عنه في `index.html` وبدّله في: `canonical` و`og:url` و`og:image` و`twitter:image` وبيانات JSON-LD.

## 8) الرفع على Cloudflare Pages

1. ادخل Cloudflare > Workers & Pages > مشروعك.
2. اختر Create new deployment (Direct upload).
3. اسحب **محتويات** المجلد (index.html + css + js + images) وليس المجلد الخارجي نفسه.
4. اضغط Deploy وانتظر ثوانٍ.

**بعد كل رفع:**
- جرّب نموذج التواصل مرة وتأكد أن الرسالة وصلت لبريدك (يحتاج تأكيد Formspree في أول مرة).
- جرّب الموقع على الموبايل، بالوضعين الداكن والفاتح، وبالعربي والإنجليزي.
- لو لم تظهر التغييرات: اضغط Ctrl+Shift+R لتحديث الكاش.
- صورة المشاركة قد تبقى قديمة في واتساب وفيسبوك حتى تحدّث الكاش من أداة Facebook Sharing Debugger.

## 9) حل المشاكل السريعة

| المشكلة | السبب والحل |
|---|---|
| قسم الأعمال فاضي بعد التعديل | فاصلة ناقصة بين بلوكين، أو `}` / `]` ناقص في `projects.js` |
| صورة المشروع لا تظهر | اسم الملف أو المسار غلط. الحروف الكبيرة والصغيرة تفرق |
| إطار مزدوج حول صورتي | غيّر `device` إلى `'none'` |
| نص إنجليزي قديم بعد تعديل العربي | عدّل ترجمته في `js/i18n.js` |
| الموقع مختلف بعد الرفع | حدّث الصفحة بـ Ctrl+Shift+R |
